### Retail DAO

<img src="https://raw.githubusercontent.com/tripl3tr3s/Retail_DAO/refs/heads/main/Images/LP-banner.png" atl="Retail DAO banner" witdth="600"/>

Welcome to Retail DAO, a decentralized organization revolutionizing retail through Web3 on the Base Network. This repository hosts our smart contracts, governance documentation, and community resources, ensuring transparency and open collaboration.

## Overview
- **Token**: $RETAIL, powering governance and incentives
- **Network**: Base Network (mainnet and Sepolia testnet)
- **Governance**: Hybrid model using Aragon for on-chain voting, Snapshot for off-chain proposals, and Discord polls for community input
- **Mission**: Build community-driven retail solutions with decentralized ownership in the quest to achieve financial freedom.

## Repository Structure
- `contracts/`: Solidity smart contracts for governance, token, and DAO operations.
- `docs/`: Documentation, including governance, token details, and interaction guides
- `scripts/`: Hardhat scripts for authorized interaction
- `test/`: Unit tests for smart contracts
- `README.md`: Project overview
- `LICENSE`: Licensing information
